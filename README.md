# zpool-monitor
Python script to monitor Zpool status.

### Setup Instructions:
1. Create venv: `python3 -m venv .`
2. Use that venv Python install to install dependencies: `./bin/pip install -r ./requirements.txt`
3. Use that venv Python to run the scripts: `./bin/python zpool-status.py` -or- `./bin/python zpool-monitor-hourly.py`
